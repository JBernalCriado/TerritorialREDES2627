Para compilar
    chmod +x make.sh
    chmod +x salir.sh
    ./make.sh


El server.sh es un bucle para ejecutar ./server una y otra vez por si se queda el puerto pillado, en tal caso
    chmod +x server.sh

El salir.sh es el script que pone la pantalla de salida en el servidor. Se puede omitir, pero queda chulo.
